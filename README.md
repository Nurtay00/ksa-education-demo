# KSA Education

Интерактивный прототип платформы обучения врачей и стоматологов.

## Демо

https://nurtay00.github.io/ksa-education-demo/

Светлый адаптивный интерфейс: кабинет обучающегося, каталог с фильтрами и поиском, страница курса, программа обучения, сертификаты и календарь.

Данные пользователей, программы, результаты и сертификаты демонстрационные. Видео, выпуск сертификатов и сохранение прогресса не подключены к серверу; некоторые действия показывают демонстрационные уведомления.

## Локальный запуск

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173 . Сборка и установка зависимостей не нужны.

## Публикация

GitHub Pages публикует корень ветки `main`. Изменения после `git push` автоматически попадают на сайт.

Основные файлы: `index.html`, `app.js`, `styles.css`, `redesign.css`, `assets/`.

Источники изображений указаны в [ASSETS.md](ASSETS.md). Прототип подготовлен для обсуждения концепции; он не является официально запущенной образовательной платформой КСА.
